## [0.0.1] - 2025-10-19

### ✨ Initial Release

- 🎉 First public release of **Feature Assured** on the VS Code Marketplace.
- ✅ Execute and validate `.feature` files directly in VS Code.
- 🔍 Inline test results, errors, and screenshots in real time.
- 🧠 Smart validation for steps using the `@yassinouhadi/cypress-generic-package`.
- 🧩 Interactive Step Explorer for browsing available steps.
- 🧾 Visual JSON Model Explorer for inspecting REST, SOAP, and GraphQL models.
- ⚙️ Schema validation for JSON configs.
- 🪄 Integration with the VS Code Problems panel.
- 💡 Ability to request new step implementations via GitHub integration.
